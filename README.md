# 日砌 — 每日打卡

**日砌**（Ri Qi）是一个面向家庭的每日打卡工具。每位家庭成员可以拥有独立的任务清单，通过滑动卡片的方式打卡，操作直观且富有仪式感。

> **日砌**：每日一砌，积少成多。出自"日积月累，砌石成塔"——每天完成一件小事，日复一日便筑成高塔。

---

## 功能一览

- **每日打卡** — 为每天创建独立的任务清单，滑动滑块完成打卡
- **撤销打卡** — 手滑了？从右往左滑回去即可取消
- **拖拽排序** — 编辑模式下按住手柄随意调整任务顺序
- **明日任务规划** — 提前规划明天的任务清单，到日子一键沿用
- **上午 / 下午分类** — 用可拖动的分界线将任务按上下午分组，一目了然
- **任务库** — 管理常用任务模板，带填空占位符，可从任务库快速导入到今日或明日任务
- **任务计时** — 每个任务可开启计时器记录用时，支持手动编辑，今日总用时一目了然
- **每日复盘** — 滑动评分、任务完成分析、文字反思、总用时统计，帮你回顾每一天
- **连续打卡保护卡** — 每连续打卡 2 天奖励 1 张保护卡，自动保护连续记录不中断
- **数据看板** — 个人数据统计：连续打卡天数、完成率、当月日历热力图
- **历史回顾** — 浏览过去每一天的任务完成记录
- **多用户** — 每位家庭成员拥有独立账号和每日任务
- **管理员面板** — 管理成员、重置密码、查看全局进度
- **局域网共享** — 同一 WiFi 下所有设备可同时使用

## 快速开始

### 启动服务器

在项目目录下打开终端，运行：

```bash
python server.py
```

启动后终端会显示：

```
  == Ri Qi - Daily Check-in ==
  本机:  http://localhost:8080
  局域网: http://192.168.x.x:8080
  第一个注册的用户自动成为管理员
  按 Ctrl+C 停止服务器
```

### 在浏览器中打开

- **本机**：浏览器打开 `http://localhost:8080`
- **其他设备（同 WiFi）**：浏览器打开终端显示的局域网地址，如 `http://192.168.x.x:8080`

### 自定义端口

```bash
python server.py 3000
```

## 第一次使用

### 注册账号

1. 在登录界面输入你的**名字**和**密码**（至少 3 个字符）
2. 点击"登录 / 注册"
3. 首次使用系统会自动创建账号；下次用同样的名字和密码即可登录
4. 登录成功后浏览器会记住你的身份，下次打开页面自动进入

> 第一个注册的人自动成为**管理员**，拥有管理成员和查看全局进度的权限。

### 添加任务

1. 点击页面右下角的 **+** 按钮
2. 在底部弹出的输入框中输入任务内容
3. 按回车或点击"添加"按钮

### 打卡完成

- 拖动任务卡片下方的滑块**从左往右**划过，卡片会以动画效果标记为完成
- 卡片完成状态会自动保存

### 取消打卡

- 已完成的任务可以再次拖动滑块**从右往左**划回去，即可取消打卡

### 编辑与删除

1. 点击右下角的 **✎** 按钮进入编辑模式
2. 编辑模式下：
   - 卡片左侧会出现 **≡** 拖动手柄，按住可拖动排序
   - 卡片右侧会出现 **✕** 删除按钮
3. 编辑模式 5 秒无操作会自动退出

## 连续打卡保护卡

保护卡是系统自动奖励的"补签卡"，在你不小心断签时自动使用，保住连续打卡记录。

- **获取方式**：每连续打卡 2 天自动获得 1 张保护卡
- **持有上限**：随连续打卡天数增长 — 20 天以内最多持有 2 张，50 天以内 5 张，超过 50 天最多 10 张
- **自动使用**：当某天有未完成的任务或完全漏打卡时，系统自动消耗一张保护卡，将该天标记为受保护，连续打卡不中断
- **查看方式**：在数据看板页面可以看到当前持有的保护卡数量和已保护的天数

## 数据看板

登录后点击侧栏的**数据看板**进入个人统计页面，展示：

- **当前连续打卡** — 正在持续的打卡天数（含保护卡自动续命）
- **最长连续打卡** — 历史最高连续打卡天数
- **本月完成** — 本月已打卡天数
- **完成率** — 所有任务的总体完成比例
- **保护卡** — 当前持有数量 / 上限
- **当月日历热力图** — 以颜色标识每一天的完成状态（绿 = 全部完成、黄 = 部分完成、蓝 = 受保护、灰 = 无数据）

## 明日任务规划

点击侧栏的**明日任务**进入规划页面：

1. 提前为明天添加任务
2. 到第二天打开应用时，明日的任务会自动成为今天的任务
3. 编辑和排序操作与今日任务完全一致

---

## 上下午分界线

在今日任务和明日任务页面，有一条可拖动的分界线，用来把任务分为「上午」和「下午」两组：

- **拖动分界线**：按住分界线上下拖动，即可调整上下午的分组位置
- **自动归类**：分界线以上的卡片归为上午，以下归为下午
- **视觉区分**：上午和下午区域有不同的标签提示，方便快速浏览

## 任务库

任务库用于管理你经常重复使用的任务模板，支持填空占位符。

### 添加模板

1. 在任务库页面输入任务内容，例如「上第__节课第__部分」
2. 点击 **⬜ 占位** 按钮，在光标位置插入填空位（`⬜`）
3. 一个任务里可以插入多个占位符
4. 点击「添加」保存到任务库

### 导入使用

在**今日任务**或**明日任务**页面，点击 **📋 任务库** 按钮：

1. 弹出任务库列表，展示所有可用模板
2. 点击模板上的填空位填入具体内容
3. 点击「导入」将填好的任务添加到对应页面
4. 支持一次性选择多个模板批量导入

## 每日复盘

在侧栏点击**每日复盘**进入当天回顾页面：

- **滑动评分**：用滑块为今天打分（1–10 分），带表情反馈
- **任务完成情况**：自动列出今天的任务及完成状态
- **文字反思**：写下今天的感想或收获
- **保存复盘**：每次保存后刷新页面不会丢失数据
- 当天数据自动关联，每个日期独立保存

---

## 任务计时

每个任务卡片下方都有一串**时间珠子**，用来记录任务用时：

- **点击珠子**：8 颗珠子，每颗 = 15 分钟，点第 N 颗前 N 颗全部亮起
- **快速设时**：点 2 颗 → 30 分钟，点 4 颗 → 1 小时，一目了然
- **归零**：点击当前亮起的最后一颗珠子，计时归零
- **视觉反馈**：珠子从暖金色渐变到暖绿色，点击时有弹跳动画
- **总用时汇总**：任务页顶部显示今日总用时（🕐 2小时35分）
- **数据看板**：展示今日总用时
- **每日复盘**：复盘页面同步显示今日总用时

## 同 WiFi 使用说明

想让其他电脑或手机也用上日砌：

1. 确保所有设备连接同一个 WiFi
2. 在启动服务器的电脑上查看启动时显示的局域网 IP
3. 其他设备在浏览器中输入这个地址
4. 每位家人各自注册自己的账号即可

### 如果局域网设备无法访问

通常是 Windows 防火墙阻止了连接。解决方法：

1. 在项目目录中找到 **`fix_firewall.bat`**
2. **右键 → 以管理员身份运行**
3. 运行一次后，防火墙规则就会永久生效

或者手动添加防火墙规则：

```
netsh advfirewall firewall add rule name="RiQi" dir=in action=allow program="C:\Python313\python.exe" protocol=tcp localport=8080
```

服务器启动时也会尝试自动添加防火墙规则（需以管理员身份运行 Python）。

## 项目结构

```
日砌/
├── server.py            # Python HTTP 后端服务器（标准库）
├── index.html           # 单页前端应用（全部内联，零依赖）
├── fix_firewall.bat     # Windows 防火墙配置脚本
├── README.md            # 本文件
└── data/                # 数据存储目录
    ├── users.json       # 用户账号信息（加盐哈希密码）
    └── {用户名}/
        ├── tasks_2026-07-13.json   # 每日任务（按日期命名）
        ├── review_2026-07-13.json  # 每日复盘数据
        ├── library.json            # 个人任务库
        ├── protection.json         # 连续打卡保护卡数据
        └── templates.json          # （已弃用）任务模板
```

## 数据与隐私

- **完全本地**：数据存储在你的电脑上，不经过任何云端服务器
- **纯文件存储**：使用 JSON 文件存储，无需数据库
- **密码安全**：密码经 SHA-256 加盐哈希存储，不保存明文
- **清理数据**：直接删除 `data/` 目录下的用户文件夹即可清除该用户所有数据

## 技术栈

| 层级     | 技术                                                   |
| -------- | ------------------------------------------------------ |
| 后端     | Python 标准库 `http.server`，轻量 HTTP 服务器          |
| 前端     | 纯 HTML + CSS + JavaScript，无框架、无构建工具         |
| 数据     | JSON 文件存储（按用户/日期分片）                        |
| 认证     | Token 机制 + `localStorage` 持久化                      |
| 设计风格 | 玻璃拟态（Glassmorphism）、暖色渐变、毛玻璃效果         |

### 设计细节

- 背景渐变动画（5 色 20 秒循环流动）
- 卡片毛玻璃效果（`backdrop-filter: blur()`）
- 打卡成功粒子动画（12 颗彩色粒子 360° 扩散）
- 卡片入场/删除/完成动画
- 响应式布局适配手机端
- 字体搭配：Caveat（英文手写）+ LXGW WenKai（霞鹜文楷中文手写）

## 开发说明

所有代码均为单文件架构，修改后刷新页面即可生效：

- **修改后端逻辑** → 编辑 `server.py`
- **修改前端界面** → 编辑 `index.html`（CSS 和 JS 全部内联于此）
- **修改数据** → 直接编辑 `data/` 下的 JSON 文件
