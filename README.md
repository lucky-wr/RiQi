# 日砌 — 每日打卡

**日砌**（Ri Qi）是一个个人每日打卡工具，通过滑动卡片的方式打卡，操作直观且富有仪式感。

> **日砌**：每日一砌，积少成多。出自"日积月累，砌石成塔"——每天完成一件小事，日复一日便筑成高塔。

---

## 功能一览

- **每日打卡** — 为每天创建独立的任务清单，滑动滑块完成打卡
- **每日进度条** — 任务页顶部吸顶显示今日完成进度，有子任务的任务只算子任务
- **昨日未完成带入** — 点击进度条旁的「昨日」，可把昨天没完成的任务带入今天；已完成的详情不会重复导入
- **任务详情** — 任务标题下可添加多条可勾选的详情项（如预习第几课），记录部分完成情况；全部勾选后主任务自动完成
- **保持亮屏** — 侧栏开关，开启后阻止屏幕自动熄灭（Windows）
- **系统托盘** — 启动后驻留托盘，可快速打开日砌、切换保持亮屏或退出程序
- **撤销打卡** — 手滑了？从右往左滑回去即可取消
- **拖拽排序** — 编辑模式下按住手柄随意调整任务顺序
- **明日任务规划** — 提前规划明天的任务清单，到日子一键沿用
- **上午 / 下午分类** — 用可拖动的分界线将任务按上下午分组，一目了然
- **任务库** — 管理常用任务模板，带填空占位符，可从任务库快速导入到今日或明日任务
- **任务计时** — 任务卡片显示累计用时，在独立计时页开始或结束计时；有详情的任务可选择某条详情计时
- **休息计时** — 一键开始休息，结束后可继续原任务或切换任务；休息数据独立统计
- **每日复盘** — 每日概览、任务用时饼图、竖向时间轴和月度完成日历，集中查看每天与每月数据
- **历史回顾** — 浏览过去每一天的任务完成记录
- **计时页面** — 独立计时页专注记录当前任务用时，支持刷新后恢复计时
- **多设备访问** — 同一 WiFi 下自己的手机/电脑也能访问（可选）

## 快速开始

### 直接运行

双击 **`RiQi.exe`** 启动。程序会驻留系统托盘，不会自动打开浏览器。

- **打开日砌**：双击托盘图标
- **保持亮屏**：右键托盘图标，勾选「保持亮屏」
- **退出程序**：右键托盘图标，选择「退出日砌」

数据会自动保存在 `RiQi.exe` 同目录的 `data` 文件夹中，不会上传到网络。

### 在浏览器中打开

- **本机**：浏览器打开 `http://localhost:8080`
- **其他设备（同 WiFi）**：浏览器打开终端显示的局域网地址，如 `http://192.168.x.x:8080`

### 自定义端口

```powershell
RiQi.exe 3000
```

## 第一次使用

### 注册账号

1. 在登录界面输入你的**名字**和**密码**（至少 3 个字符）
2. 点击"登录 / 注册"
3. 首次使用系统会自动创建账号；之后只能用同一个账号登录，无法再创建其他账号
4. 登录成功后浏览器会记住你的身份，下次打开页面自动进入

### 添加任务

1. 点击页面右下角的 **+** 按钮
2. 在底部弹出的输入框中输入任务内容
3. 按回车或点击"添加"按钮

### 打卡完成

- 拖动任务卡片下方的滑块**从左往右**划过，卡片会以动画效果标记为完成
- 卡片完成状态会自动保存

### 取消打卡

- 已完成的任务可以再次拖动滑块**从右往左**划回去，即可取消打卡

### 编辑与删除

1. 点击右下角的 **✎** 按钮进入编辑模式
2. 编辑模式下：
   - 卡片左侧会出现 **≡** 拖动手柄，按住可拖动排序
   - 卡片右侧会出现 **✕** 删除按钮
3. 编辑模式 5 秒无操作会自动退出

## 明日任务规划

点击侧栏的**明日任务**进入规划页面：

1. 提前为明天添加任务
2. 到第二天打开应用时，明日的任务会自动成为今天的任务
3. 编辑和排序操作与今日任务完全一致

---

## 上下午分界线

在今日任务和明日任务页面，有一条可拖动的分界线，用来把任务分为「上午」和「下午」两组：

- **拖动分界线**：按住分界线上下拖动，即可调整上下午的分组位置
- **自动归类**：分界线以上的卡片归为上午，以下归为下午
- **视觉区分**：上午和下午区域有不同的标签提示，方便快速浏览
- **分区用时统计**：每个分区标题旁显示该时段已完成用时和总用时（如「已完成 25m · 总计 40m」）

## 任务库

任务库用于管理你经常重复使用的任务模板，支持填空占位符。

### 添加模板

1. 在任务库页面输入任务内容，例如「上第__节课第__部分」
2. 下方可再输入**详情模板**（可选），例如「第__课 第__节」；一行一条，导入后会变成多条可勾选的详情项
3. 点击 **⬜ 占位** 按钮，在光标位置插入填空位（`⬜`）
4. 一个任务里可以插入多个占位符
5. 点击「添加」保存到任务库

### 导入使用

在**今日任务**或**明日任务**页面，点击 **📋 任务库** 按钮：

1. 弹出任务库列表，展示所有可用模板
2. 点击模板上的填空位填入标题和详情内容
3. 点击「导入」将填好的任务添加到对应页面
4. 支持一次性选择多个模板批量导入

## 每日复盘

在侧栏点击**每日复盘**，页面按顺序展示四块数据：

- **每日概览**：显示完成度、有记录任务数、计时区间和最长专注时长
- **总休息时长与次数**：只统计超过 3 分钟的休息，且不计入任务完成率
- **任务用时占比**：可切换“主任务”“详细任务”和“工作与休息”三种饼图，详细模式会拆分到具体详情
- **双模式时间轴**：展开模式显示每个计时块的详细信息；全天模式用一根 00:00–24:00 的竖向时间尺直观展示任务与休息的时间位置和长度，并提供学科颜色说明
- **月度完成情况**：用日历热力图展示整月完成状态，可切换月份，点击日期可回看当天数据

时间轴依赖计时开始和结束记录。旧数据只有累计用时，因此无法还原历史日期的时间轴；从当前版本开始产生的计时记录会正常显示。

### 回看历史数据

复盘页顶部有 **◀ 日期 ▶** 切换按钮，也可以直接点击月度日历中的日期。页面不支持查看未来日期，点击“今天”即可返回当天。

## 任务计时

任务卡片只显示每项任务当前的累计用时，计时操作统一放在独立计时页：

- **开始任务计时**：在计时页选择任务后点击「开始计时」
- **结束任务计时**：再次点击「结束计时」，超过 3 分钟后按最近 5 分钟累加
- **开始休息**：任务计时中点击「开始休息」会先结束并记录当前任务；休息结束后可继续原任务或选择其他任务
- **休息记录**：不超过 3 分钟的休息不记录；超过 3 分钟才计入休息次数和工作/休息占比
- **详情计时**：计时页「当前任务」里点有详情的任务会展开，可选中某条详情开始计时，时间会记到该详情上
- **总用时汇总**：任务页顶部、上午/下午分区标题和每日复盘均显示今日总用时

## 多设备访问（可选）

想在手机或另一台电脑上继续用日砌：

1. 确保所有设备连接同一个 WiFi
2. 在启动服务器的电脑上查看启动时显示的局域网 IP
3. 其他设备在浏览器中输入这个地址
4. 用自己的账号登录即可，数据仍保存在服务器这台电脑上

### 如果局域网设备无法访问

通常是 Windows 防火墙阻止了连接。首次启动时如果出现防火墙提示，请允许日砌通过专用网络。也可以以管理员身份执行：

```
netsh advfirewall firewall add rule name="RiQi" dir=in action=allow program="C:\path\to\RiQi.exe" protocol=tcp localport=8080
```

程序启动时也会尝试自动添加防火墙规则（需要管理员权限）。

## 项目结构

```
日砌/
├── RiQi.exe             # Windows 单文件程序
├── server.py            # Python HTTP 后端服务器（标准库）
├── index.html           # 单页前端应用（全部内联，零依赖）
├── start_riqi.bat       # Windows 启动脚本
├── README.md            # 本文件
└── data/                # 数据存储目录
    ├── users.json       # 用户账号信息（加盐哈希密码）
    └── {用户名}/
        ├── tasks_2026-07-13.json   # 每日任务（按日期命名）
        ├── review_2026-07-13.json  # 旧版复盘数据（已弃用）
        ├── library.json            # 个人任务库
        └── templates.json          # （已弃用）任务模板
```

## 数据与隐私

- **完全本地**：数据存储在你的电脑上，不经过任何云端服务器
- **纯文件存储**：使用 JSON 文件存储，无需数据库
- **密码安全**：密码经 PBKDF2（SHA-256，20 万次迭代）加盐哈希存储，不保存明文
- **清理数据**：直接删除 `data/` 目录下的用户文件夹即可清除该用户所有数据

## 技术栈

| 层级     | 技术                                                   |
| -------- | ------------------------------------------------------ |
| 后端     | Python 标准库 `http.server` + `pystray` 系统托盘       |
| 前端     | 纯 HTML + CSS + JavaScript，无框架、无构建工具         |
| 数据     | JSON 文件存储（按用户/日期分片）                        |
| 认证     | Token 机制 + `localStorage` 持久化                      |
| 设计风格 | 玻璃拟态（Glassmorphism）、暖色渐变、毛玻璃效果         |

### 设计细节

- 背景渐变动画（5 色 20 秒循环流动）
- 卡片毛玻璃效果（`backdrop-filter: blur()`）
- 打卡成功粒子动画（12 颗彩色粒子 360° 扩散）
- 卡片入场/删除/完成动画
- 响应式布局适配手机端
- 字体搭配：Caveat（英文手写）+ LXGW WenKai（霞鹜文楷中文手写）

## 开发说明

所有代码均为单文件架构，修改后刷新页面即可生效：

- **修改后端逻辑** → 编辑 `server.py`
- **修改前端界面** → 编辑 `index.html`（CSS 和 JS 全部内联于此）
- **修改数据** → 直接编辑 `data/` 下的 JSON 文件
